## Selected work

| Project | What it is |
| --- | --- |
| [skill-factory](https://github.com/enspdf/skill-factory) | Go CLI and TUI. One static binary. Setup, doctor, and an editor with a tree, a graph, and an inspector. |
| [api-2-mcp](https://github.com/enspdf/api-2-mcp) | One MCP server in front of your HTTP APIs. OpenAPI when a spec exists, live probing when it does not. Bun, no runtime npm dependencies. |
| [browser-experience-auditor](https://github.com/enspdf/browser-experience-auditor) | Records a session — by hand, from a script, or attached to Chrome — and writes findings plus Playwright tests. |
| [Forge](https://github.com/enspdf/forge-coach-app) | Trainers build routines, invite clients, and track adherence. Expo, Bun, Hono, Postgres. |
| [finetune-local](https://github.com/enspdf/finetune-local) | Fine-tune a small model on this Mac with MLX. The adapter learns a voice or a coding habit. |
| [cqrs-architecture](https://github.com/enspdf/cqrs-architecture) | Five small apps — Rust, Express, Hono, Spring, Node — for when the write model and the read model should differ. |
| [Flora-Link](https://github.com/enspdf/flora-link) | Inventory for wholesale flower distributors. Lots, shipments, FIFO, invoices. Next.js. |
